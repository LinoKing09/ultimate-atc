# Airports

Every airport is built after the [airport recipe](../airport-data.md#adding-an-airport---the-recipe): OpenStreetMap layout, facts from the national AIP (DFS; AIP Thailand; AIP Ecuador; Dutch Caribbean eAIP; in the US the FAA Chart Supplement; for Wellington the VATNZ procedures, as the AIP New Zealand allows personal use only), procedures after VATSIM, checked against the charts.
